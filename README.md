# 🌐 Stefenis Pietersz Portfolio

A personal portfolio website showcasing my skills, projects, and experience as a developer.  
This project is built using **HTML**, **CSS**, and **JavaScript**, and serves as an online resume and project showcase.

## 📌 About

This portfolio highlights my:

- Personal and academic projects
